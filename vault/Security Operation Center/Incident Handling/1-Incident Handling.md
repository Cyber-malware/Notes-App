An `event` is an action occurring in a system or network. An `incident` is an event with a negative consequence. One example of an incident is a system crash. 

Incident handling is a clearly defined set of procedures for managing and responding to security incidents in a computer or network environment.
![[Pasted image 20260614144525.png]]

One of the most widely used resources on incident handling is [NIST's Computer Security Incident Handling Guide](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-61r3.pdf) help in mitigating risk from incidents.
