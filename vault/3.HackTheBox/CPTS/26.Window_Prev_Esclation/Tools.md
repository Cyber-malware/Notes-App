
| Tool                                                                                                | Description                                                                                                                                                                                      |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Seatbelt](https://github.com/GhostPack/Seatbelt)                                                   | C# project for performing a wide variety of local privilege escalation checks.                                                                                                                   |
| [winPEAS](https://github.com/peass-ng/PEASS-ng/tree/master/winPEAS)                                 | Script that searches for possible paths to escalate privileges on Windows hosts; many checks are explained in its documentation.                                                                 |
| [PowerUp](https://raw.githubusercontent.com/PowerShellMafia/PowerSploit/master/Privesc/PowerUp.ps1) | PowerShell script for finding common Windows privilege escalation vectors that rely on misconfigurations; can also exploit some discovered issues.                                               |
| [SharpUp](https://github.com/GhostPack/SharpUp)                                                     | C# version of PowerUp.                                                                                                                                                                           |
| [JAWS](https://github.com/411Hall/JAWS)                                                             | PowerShell script (compatible with PowerShell 2.0) for enumerating privilege escalation vectors.                                                                                                 |
| [SessionGopher](https://github.com/Arvanaghi/SessionGopher)                                         | PowerShell tool that finds and decrypts saved session information for remote-access tools (PuTTY, WinSCP, SuperPuTTY, FileZilla, RDP).                                                           |
| [Watson](https://github.com/rasta-mouse/Watson)                                                     | .NET tool designed to enumerate missing KBs and suggest exploits for privilege escalation vulnerabilities.                                                                                       |
| [LaZagne](https://github.com/AlessandroZ/LaZagne)                                                   | Tool for retrieving passwords stored on a local machine from browsers, chat tools, databases, Git, email, memory dumps, PHP/sysadmin tools, wireless configs, Windows internal stores, and more. |
| [Windows Exploit Suggester - Next Generation (WES‑NG)](https://github.com/bitsadmin/wesng)          | Based on `systeminfo` output; provides a list of vulnerabilities and matching exploits for Windows OS versions from XP through Windows 10 (and corresponding Server versions).                   |
| [Sysinternals Suite](https://learn.microsoft.com/en-us/sysinternals/downloads/sysinternals-suite)   | Collection of Windows utilities; commonly used tools for enumeration include `AccessChk`, `PipeList`, and `PsService`.                                                                           |
